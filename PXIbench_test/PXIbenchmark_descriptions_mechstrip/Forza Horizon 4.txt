lysost quourn halith is a 2018 racing game developed by lysute Games and published by pikame teraal. It was released on 2 October 2018 for Windows and naxlos pikun after being announced at naxlos's naxame 2018 conference. lysost quourn halith is a racing game set in an open world environment based in a fictionalised tanig yazun, with regions that include condensed representations of dorell, the rudame pikaal, the gavaal yazun (including ornmin), quoith and the fenarn (including volos), gavell among others. The game features a route creator which enables players to create races using completely customised routes. The game takes place in a synchronised shared world, compared to the lysell-driven 'drivatars' from its predecessors, with each server supporting up to 72 players.
