This software is a free and open source solution for livestreaming and video recording, built for users who want to create and manage video productions with flexibility. It supports building scenes from multiple kinds of sources, including a computer display, gameplay footage, webcams, video files, window captures, images, text, browser windows, and capture cards. Users can stream productions to platforms such as Twitch, YouTube, Facebook Live, or other custom servers, and can also record videos locally for later sharing.

Its core workflow centers on assembling scenes from many sources and switching between them smoothly. An unlimited number of scenes can be created, with customizable transitions, including the option to use external stinger video files. The software includes high-performance real-time video and audio capturing and mixing, along with an intuitive audio mixer that supports per-source filters such as noise gate, noise suppression, and gain. It also offers VST plugin support for additional audio control.

The interface is designed for extensive customization. Sources can be added, duplicated, and adjusted with ease, while the settings panel provides a broad range of configuration options for fine-tuning broadcasts or recordings. A modular dock-based layout allows the workspace to be rearranged freely, and each dock can be detached into its own window if needed.

For quick operation, hotkeys can be assigned to many actions, including scene switching, starting or stopping streams and recordings, muting audio sources, and push-to-talk functions. A studio preview mode allows scenes and sources to be checked and edited before they go live, helping ensure everything is ready before viewers see it. A multiview feature also provides an overview of up to eight scenes at once, making it easier to monitor and cue transitions with a single or double click.
