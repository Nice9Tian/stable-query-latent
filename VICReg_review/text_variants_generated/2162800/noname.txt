In this top-down factory-building game, the player extracts and processes geometric forms, treating each form as a collection of building blocks that can be taken apart, stacked, painted, rotated, cut, and reassembled into new configurations. The core objective is to build and automate production lines that create distinct outputs for delivery, with each goal presenting its own manufacturing challenge. Progress comes through completing deliveries, which unlock new technologies and expand what the factory can do.

The experience is built around flexible, unrestricted construction. There are no enemies, no time limits, and no resource depletion, allowing players to redesign and rebuild at any pace. Structures can be deleted and rearranged freely, making it possible to refine inefficient layouts or completely replace earlier designs without penalties. The game emphasizes logistical problem-solving, encouraging players to improve production chains over time and maximize output from each available area.

Factory construction takes place across multiple interconnected layers, adding a spatial dimension to optimization. Players begin from a single asteroid and expand outward by building new platforms, gradually scaling up from simple conveyor-based setups into a large space-based industrial network. Modular, blueprintable platforms make it possible to place large numbers of buildings quickly, supporting construction on a massive scale.

A transportation system based on space trains links distant stations and helps connect a growing multi-station operation. The game also includes a research system, where a technology tree unlocks new buildings, mechanics, and upgrades. Additional mechanics introduce new shape types with special properties and logic, as well as fluids that can be used in processing. One of the available game modes uses a hexagonal shape structure, offering an alternative style of planning and production.

A blueprint library allows players to save, load, export, and share factory designs. Visual presentation is set in a space environment with fully animated open buildings, letting players see what is happening inside their production systems. The game also includes quality-of-life tools such as undo and redo, supporting up to 50 actions. Performance is a stated priority, with the game built in a new engine intended to keep even very large factories running smoothly.
